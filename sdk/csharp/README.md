# C# Card SDK

Use the kit flake's `lib.${system}.csharpCard` builder in your Card definition.
Pass the directory containing your C# source as `src` and the core-generated
directory containing `_contract.json`, `_inputs.fbs`, `_outputs.fbs`, and
`_params.fbs` as `contract`.

```nix
{ csharpCard, contract, ... }:
{
  run = csharpCard {
    src = ./src;
    inherit contract;
  };
}
```

For a contract with an input and output named `number`, both with a `Value`
field, put this in `src/Card.cs`:

```csharp
using Tsugumi;
using static Tsugumi.Effects;

public static class Card
{
    public static Output Run(Input input)
    {
        var value = input.Number.Value + 1;
        Display((double)value);
        return new Output { Number = new() { Value = value } };
    }
}
```

`Input` and `Output` have one property per port with its initial letter
capitalized. Inputs and outputs use the native C# object types generated by
`flatc`, including union wrappers. Optional inputs are nullable and optional
outputs can be omitted. Assign every required output. `Input.Params` is the
generated parameter object.

File and Directory objects carry paths in `Value`. Write new outputs under
the working directory and finish writing them before returning. A Directory
output contains regular files. A File or Directory input may be forwarded
by returning its path unchanged.

`Effects.Display` supports text, scalar values, markdown, tables, images,
points, line charts, Plotly, Vega-Lite, and custom modules. Pass
`record: true` to record the display. The return value is zero when the host
accepts it. A background thread can keep displaying between calls.
`Effects.Cancelled()` and `Effects.RemainingMilliseconds()` can be queried
from any thread. Between calls they return `true` and `0`, respectively.
An active call with no deadline can report `-1`.

Throw `new Failure(FailureKind.cancelled, "stopped")` to return a typed
failure. `FailureKind` is in `Tsugumi.Data`. The SDK includes the source
file and line and accepts an optional `cell`. Ordinary exceptions map to
`worker_failed`. An `OperationCanceledException` maps to `cancelled`,
or to `timeout` when no time remains.

The builder defaults to Nixpkgs' .NET 10 SDK and permits a `dotnet` override.
It returns a derivation containing `lib/main.so` and retains the managed Card
and runtime as Nix dependencies. For external NuGet dependencies, supply
both `lock = ./packages.lock.json` and `hash` (the NAR hash of the package
feed defined by the lock). Use `lib.fakeHash` to get the expected hash from
the first build. Restore uses the locked local feed in the build sandbox.
