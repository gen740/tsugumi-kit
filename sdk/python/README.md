# Python SDK for Card ABI 9

`lib.<system>.pythonCard { src; contract; }` builds a Card that embeds CPython
in `lib/main.so`. Set `src` to the directory containing `main.py` and
`contract` to the generated directory containing `_contract.json`,
`_inputs.fbs`, `_outputs.fbs`, and `_params.fbs`. The builder also accepts
`python` to select a nixpkgs interpreter and `packages` to select dependencies
from its package set, such as `packages = ps: [ ps.matplotlib ];`. Use
`tools = [ pkgs.coreutils ];` for commands launched with `subprocess.run`.
See [Runtime tools](../../README.md#runtime-tools).

```python
import tsugumi
from card import Input, Output
from outputs.next.Number import NumberT


def run(input: Input) -> Output:
    result = NumberT()
    result.value = input.number.value + input.params.increment
    tsugumi.send(tsugumi.Scalar(result.value, "Next"))
    return Output(next=result)
```

The example assumes a `number` input, an `increment` parameter, and a `next`
output. Look in the derivation's `lib/python/card.py` for your Card's
generated fields and object types. Missing optional inputs are `None`, and
optional outputs can be omitted. FlatBuffers string accessors return bytes
for ordinary data fields. A union has a discriminator field and a value field,
both generated by `flatc`. Leave both at their defaults for an absent union.
Set both to the matching tag and generated object when returning a value.
The builder appends underscores to reserved port namespaces as needed for
Python and C++. For example, a port named `from` normally has a Python field
`from_` and a module such as `inputs.from_.Number`.

File and Directory inputs expose `value` as a filesystem string that can be
passed directly to `pathlib.Path`. Outputs accept strings, path-like objects
such as `Path`, and bytes. Create files and directories under the Card's
working directory and finish writing before returning. To forward an input,
assign its unchanged path to the matching output type.

Use `tsugumi.send(value)` for text, numbers, `Markdown`, `Scalar`, `Table`,
`Image`, `LineChart`, `Points`, and `Plotly`. Declare `views = sdk.views;`
alongside `run` in your Card's `default.nix`, with `sdk` from
`lib.${system}.pythonSdk`.

```python
tsugumi.send(tsugumi.LineChart([
    tsugumi.LineSeries("squared", "Squared", [0, 1, 2], [0, 1, 4]),
]))
tsugumi.send(tsugumi.Points([1, 0], [0, 1], [0, 0], colors=[0xff4040, 0x40aa40]))
```

Each line series takes equal-length finite x/y sequences. Point coordinates
are x/y/z sequences of the same length. Omit colors to use the default, or
provide one packed `0xRRGGBB` integer per point. The point view skips non-finite
positions.

Append custom views with `views = sdk.views ++ [ ... ];` and publish their
payloads with `tsugumi.send(view, bytes)`. The named view defines the bytes'
format. Argument and encoding errors raise exceptions before calling the host.
The SDK raises `RuntimeError` if the host cannot accept the message.
See the [view protocol](../../docs/cpp-sdk.md#display-a-value).

Call `tsugumi.send(tsugumi.Plotly(fig))` with a Plotly figure, or pass a
figure dictionary to `tsugumi.Plotly`. Add `packages = ps: [ ps.plotly ];` to
construct figures with Plotly in Python. A JSON-compatible dictionary works
without that Python dependency. The HTML file embeds Plotly.js.

The SDK sets `MPLCONFIGDIR` under `HOME` before importing the Card.
With Matplotlib installed, use `tsugumi.send(tsugumi.mpl.figure(fig))`
after importing `tsugumi.mpl`. The adapter uses IPAexGothic as a fallback for
Japanese glyphs when rendering the figure. Card threads can send live updates
between calls. Between calls `tsugumi.cancelled()` returns true and
`tsugumi.remaining_ms()` returns zero.

Raise `tsugumi.Failure("validation_failed", message)` to control the failure
kind. Unhandled Python exceptions produce a `worker_failed` result. The
SDK reports the source line when it can identify a frame in the Card source.

Build `checks.<system>.pythonAbi9` to run the Python Card with the shared
fake host.
