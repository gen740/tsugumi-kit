# Templates

These examples target **Card ABI 9 (unreleased)**. Their C++ Cards require the
upcoming ABI 9 integration in Tsugumi.

| Template | What you can copy |
| --- | --- |
| [Filter channel counts](filter-counts/) | A C++ Card that filters a CSV File, forwards the original and shows a live table preview. |
| [Convert a temperature](temperature-conversion/) | An Input Card wired to a C++ Card, with a layout fragment for the pair. |
| [Normalize text with Go](go-normalize-text/) | An Input Card wired to a Go Card that collapses whitespace and returns a text File. |
| [Number lines with Rust](rust-number-lines/) | An Input Card wired to a Rust Card that numbers the lines and returns a text File. |

See the [template guide](../docs/templates.md) for the format and Git import fields.
