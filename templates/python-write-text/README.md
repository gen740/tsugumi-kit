# Write text with Python

The Python Card writes its text parameter to `message.txt`, displays the
filename, and returns a one-file Artifact. Edit `definitions/write/params.nix` to change the value.
Set `keep_output` to `false` there to remove the Artifact when its run ends.

Git import subdirectory `templates/python-write-text`.
